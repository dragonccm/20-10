Customization comparison:
Canva documents grouping, multiple selection, locks, ordering/alignment, typography,
media replacement/cropping, page formats and several export types. Bloom's current
canvas supports single-layer editing, layer ordering, alignment, rotation, crop,
filters, locked layers, undo/redo, page ordering and explicit AI preview/apply.
Multi-select/grouping, richer connector editing and batch resizing remain advanced
work for subsequent releases rather than being represented by non-working buttons.

AI:
Canvas editing now proposes validated operations for the current page or selected
layer. It preserves unrelated layers, blocks locked-layer edits, excludes image
bytes and source URLs from the request, checks stale proposals, and applies only
on user action. Undo restores the previous page. Code/web/email have isolated HTML
proposal previews and explicit apply/undo. Existing Writing and Career AI tools
remain available. There is no Canva Connect/autofill integration or claim of free
access to paid Canva APIs.

Performance work:
Only the active category's 20 cards are mounted. Original templates require no
network-loaded deck JSON or bundled third-party fonts. Presentation/embed viewers,
CV previews and AI validation are loaded on demand. Decoded images use a bounded
cache. Canvas drag updates use animation frames. Removed global console-clearing
intervals and input-blocking handlers. Tiny's embedded media is externalized with
byte-for-byte checks, reducing the initial HTML while keeping the media unchanged.

Studio refinement (2026-11-13):
Fixed-size contextual toolbar prevents canvas rescaling when selecting a layer.
Stable scrollbar gutters and a separate overlay root preserve workspace geometry.
Short opacity transitions respect reduced-motion preferences; busy buttons retain
their label dimensions. Saved fields restore before paint; storage writes debounce
and flush on page hide/unmount. Preview and editor share one element renderer.
Original vector still lifes replace repeated mountain placeholders, with aspect-
correct crops and measured text fitting. Only the current collection is offered;
older canvas drafts remain in local storage. No Canva assets are redistributed.

Original Office template filling (2026-11-13):
DOCX and PPTX packages are edited in place at exact text spans. Original styles,
media, relationships, tables, headers/footers and slide masters are retained.
Placeholders split across runs, inline text replacements, explicit line breaks,
and empty table cells are supported. Untouched package entries are byte-identical
after decompression. This preserves formatting; it does not guarantee identical
line breaks or pagination when the replacement content has a different length.
AI detects candidate fields and maps uploaded/pasted content into proposals with
exact source quotes. The user reviews and applies values before export. Source
text is processed in bounded batches without silently dropping the end of a file.
ZIP scanning/export runs in a worker; cancellation leaves the source untouched.
Drafts stay in memory during client navigation; reload/closing the page clears
them, so users download their result before leaving the browser session.
Validated with rendered Word and PowerPoint files, mixed run styles, split
markers, blank table cells and unchanged binary package parts.
Bloom favicon: original sprout SVG, served through the Next.js icon route.
